오늘 캐시백트래커 홈 화면에 세 가지 기능을 추가했다.

기록과 관리에 집중하던 앱이었는데, 이제는 확인해야 할 정보와 소통 지점도 조금 더 자연스럽게 붙기 시작했다.

이번에 들어간 기능은 아래와 같다.

## 1. 뽐뿌 재테크포럼 인기글 배너 추가

홈에서 바로 뽐뿌 재테크포럼 인기글을 확인할 수 있도록 배너를 추가했다.

기준은 조회수 1000 이상 게시글이며, API 서버에서 30분 단위로 캐싱해서 가져오도록 구성했다.

이 기능을 넣은 이유는 단순하다.

나 역시 카드, 결제, 실사용 팁 같은 정보를 뽐뿌 재테크포럼에서 많이 얻어왔기 때문이다.

앱 안에서 관리만 하고 끝나는 것이 아니라, 실제로 도움이 될 만한 흐름을 홈에서 바로 이어주고 싶었다.

지금은 뽐뿌 재테크포럼부터 붙였지만 유용한 정보원이 더 있다면 추후에 추가할 생각이다.

## 2. 의견 보내기 버튼 추가

상단에 의견 보내기 버튼도 넣었다.

구글폼으로 연결되도록 구성해서, 사용자가 불편했던 점이나 필요 기능을 바로 전달할 수 있게 했다.

혼자 쓰려고 만들기 시작한 앱이지만 실제로 계속 다듬으려면 결국 사용자 피드백을 받는 구조가 필요하다고 봤다.

앱 내부에서 복잡한 문의 시스템을 직접 만드는 것보다, 지금 단계에서는 구글폼 방식이 훨씬 가볍고 현실적이다.

## 3. 릴리즈 노트 추가

릴리즈 노트도 함께 추가했다.

캐시백트래커는 하이브리드 앱이라서 스토어 업데이트만으로 모든 변화가 바로 전달된다고 보기 어렵다.

그래서 어떤 점이 바뀌었는지, 무엇이 개선되었는지, 사용자가 확인할 수 있는 흐름이 있으면 좋겠다고 판단했다.

기능을 조금씩 계속 손보는 프로젝트인 만큼, 릴리즈 노트는 단순 공지보다 개발 기록과 사용자 안내를 같이 맡는 역할에 가깝다.

## 정리

이번 업데이트는 거창한 기능 추가보다는 홈 화면의 실용성을 높이는 쪽에 가깝다.

관리 도구로서의 성격은 유지하되, 정보 탐색, 의견 수집, 개선 내역 공유까지 한 화면에서 이어지도록 다듬었다.

앞으로도 실제 사용 흐름에서 필요한 요소를 하나씩 붙여나갈 생각이다.
