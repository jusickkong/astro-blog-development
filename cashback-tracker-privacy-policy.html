개인정보처리방침

시행일: 2026년 3월 9일

캐시백 트래커(이하 "본 앱")는 사용자의 개인정보를 중요하게 여기며, 개인정보보호법 등 관련 법령을 준수합니다.

1. 수집하는 정보

  • Google 계정 정보: Google 로그인 시 이름, 이메일 주소, 프로필 사진 (인증 목적)
  • 앱 사용 데이터: 사용자가 직접 입력한 카드 이벤트 정보 (카드사, 신청일, 캐시백 금액 등)

2. 수집 목적

  • 로그인 및 사용자 식별
  • 기기 간 데이터 동기화 (서버 백업/복원)
  • 앱 핵심 기능 제공

3. 데이터 저장 및 처리

  • 입력한 카드 이벤트 데이터는 기기 내부(로컬)에 저장됩니다.
  • 동기화 기능 사용 시 암호화된 연결(HTTPS)을 통해 서버에 전송·저장됩니다.
  • 서버 데이터는 해당 Google 계정과 연결되며, 앱 기능 제공 목적으로만 사용됩니다.
  • 제3자에게 판매하거나 제공하지 않습니다.

4. 제3자 서비스

  • Google Firebase: 인증 및 서버 인프라 제공 (Google 개인정보처리방침)
  • Google AdMob: 광고 표시. AdMob은 광고 최적화를 위해 광고 식별자를 사용할 수 있습니다. (Google 개인정보처리방침)

5. 데이터 보관 및 삭제

  • 서버에 저장된 데이터는 계정 탈퇴 또는 삭제 요청 시 파기합니다.
  • 데이터 삭제를 원하시면 아래 연락처로 문의해 주세요.

6. 사용자의 권리

사용자는 언제든지 본인의 데이터 열람, 수정, 삭제를 요청할 수 있습니다.
